# Вариант

Сайт создаёт тренировочную контрольную по фото, PDF, файлу TXT или вставленному тексту. Задания можно распечатать или сохранить как PDF через диалог печати. Ответы и краткие решения открываются отдельным блоком.

## Запуск на компьютере

Понадобится Node.js 24 или новее. Открой PowerShell и выполни:

```powershell
git clone https://github.com/algazinajuv-ops/variant.git
cd variant
npm start
```

Открой в браузере `http://127.0.0.1:8787/`. Проект не требует установки пакетов.

Нажми **Посмотреть пример**, чтобы попробовать интерфейс без ключа. Для работы со своими файлами введи ключ OpenAI API через **Настройки ИИ**. Ключ хранится в памяти вкладки до её обновления или закрытия. API использует квоту проекта OpenAI.

На своём компьютере можно задать `OPENAI_API_KEY` в переменных окружения или в файле `.env` рядом с `package.json`, чтобы не вводить ключ в браузере. Файл `.env` исключён из Git. По умолчанию используется модель `gpt-4.1-mini`, её можно изменить через `OPENAI_MODEL`.

## Развёртывание для телефона

Локальный сервер доступен на компьютере по адресу выше. Чтобы открыть приложение с других устройств, разверни его на хостинге с HTTPS. Команда `npm run build` создаёт единый модуль Cloudflare Workers в `dist/server/index.js`. У него есть и интерфейс, и обработчик запросов к OpenAI.

У приложения есть серверная часть, поэтому GitHub Pages для этой сборки не подходит. При размещении на публичном хостинге используй личные ключи посетителей. Если задаёшь общий серверный ключ, закрой доступ к сайту через систему авторизации хостинга.

## Что делает код

- `index.html` задаёт поля загрузки и область результата. `styles.css` управляет внешним видом и складывает колонки на узком экране.
- `app.js` читает файл, уменьшает крупные фото и отправляет запрос на сервер. Затем показывает задания и скрывает ответы до нажатия.
- `server.mjs` проверяет формат и размер, передаёт исходник в OpenAI и проверяет структуру ответа. Файлы не записываются в хранилище сайта.
- `build.mjs` собирает файлы сайта в единый Worker для хостинга.

Загружай одну работу до 10 МБ. Для нескольких страниц подойдёт один PDF. Если на работе есть имя или другие личные данные, их можно закрыть перед загрузкой.
